# Installationsanleitung für Agenten

## Ziel und Entscheidungen

Die README enthält einen kopierbaren Auftrag und verweist auf eine eigenständige Anleitung für installierende Agenten. Sie behandelt die vollständige gebündelte Skill, Voraussetzungen, eine Installation im passenden Geltungsbereich und überprüfbare Schritte. Agenteneigene Installationsmechanismen haben Vorrang; falls diese nicht verfügbar sind, beschreibt die Anleitung das Kopieren in dokumentierte Skill-Verzeichnisse. Eine agentenspezifische Komplettanleitung allein würde den allgemeinen Ablauf unnötig duplizieren; ein behaupteter universeller Installationspfad wäre nicht verlässlich.

Offizielle Dokumentation belegt Beispiele für Codex, Claude Code und GitHub Copilot. Grenzen und nicht selbst ausgeführte Integrationstests sind auszuweisen. Der Nutzer testet verschiedene Coding-Agenten später manuell. Bereits vorhandene Installationen dürfen nicht stillschweigend überschrieben werden. Die Umsetzung ändert keine Laufzeitlogik.
