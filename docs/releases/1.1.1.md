# 1.1.1

- Suchergebnisse werden nach Erstveröffentlichung sortiert und `--veroeffentlichtseit` lokal auf den gewünschten Zeitraum eingegrenzt. Die API-Vorauswahl beruht auf empirischen, nicht garantierten Stufen; Einzelheiten und Grenzen stehen in der Nutzungsanleitung.
- Treffer mit unklarem Erstveröffentlichungsdatum bleiben erhalten; ihre Anzahl wird auf stderr gemeldet. Die JSON-Ausgabehülle bleibt unverändert.
